# Jumpscare (Forge 1.20.1)

Muestra una imagen al azar a pantalla completa con sonido, cada cierto tiempo.

## Comandos (requieren OP)
- `/gamerule jumpscareEnabled false` desactiva, `true` activa
- `/gamerule jumpscareIntervalTicks 20` intervalo en ticks (20 = 1 s, minimo 1 = 50 ms)

## Descargar
Ve a **Releases** (columna derecha del repositorio) y baja el `.jar`.
Instalalo en el servidor y en cada cliente (carpeta `mods`, con Forge 1.20.1).

Aviso: las imagenes muy rapidas pueden danar a personas fotosensibles.
